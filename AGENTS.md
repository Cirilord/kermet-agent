# Kermet Agent Guide

This file is the entry point for anyone—human or agent—working in this repository.

Read the relevant documentation in `docs/` before making a change. Keep this file short: it is an index, while project guidance belongs in the documents it links to.

## Working rules

1. Read the documents relevant to the change before editing code.
2. Follow the architecture and conventions documented in `docs/`.
3. Update the relevant document when a change introduces or alters a lasting decision, convention, or workflow.
4. Keep user-facing copy, source code, documentation, commit messages, and identifiers in English.
5. Do not place detailed conventions, architecture, or policy in this file; add them to the appropriate document in `docs/` and link them here.
